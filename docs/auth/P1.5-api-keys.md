# P1.5 — API Keys: First-Class Identity Surface

## Purpose

Ship API keys as the default authentication mechanism for MOA. After this
prompt, a fresh `make dev` stack lets a developer:

1. Create an API key for a user (via `moa-cli`).
2. Present it to `moa-edge` as `Authorization: Bearer moa_dev_...`.
3. Hit a real handler (e.g., session create); `require_authz` allows or
   denies based on actual FGA tuples on the api_key subject.
4. Rotate or revoke the key; revocation is enforced at the next request.
5. Have the key auto-revoked if it leaks to a public GitHub repository
   (secret-scanning partner integration).

This is the gate-marking prompt for Phase 1: the first end-to-end auth flow
that ties P1.0–P1.4 together with a usable user-facing surface.

End state:

- New crate `moa-auth-providers` containing the `api_keys` module
  (storage, hashing, format) and a `LocalAuthProvider` that implements
  `moa_core::traits::AuthProvider`. The crate is structured so P1.6 can
  add Null + Builtin providers alongside without restructuring.
- Per-crate sqlx migration creates `api_keys` and `api_key_revocations` tables.
- `moa-cli auth keys create | list | rotate | revoke` works against the
  orchestrator.
- `moa-edge` swaps out `RejectAllAuthProvider` for `LocalAuthProvider`.
- API key issuance writes the FGA `api_key:<id> owner <user|agent>:<owner>`
  tuple via the outbox (same Postgres tx as the `api_keys` row insert).
- GitHub secret-scanning partner registration: the public regex
  `moa_(live|prod|stg|dev)_[a-zA-Z0-9]{32}_[a-f0-9]{8}` is registered, and
  `POST /v1/security/secret-scanning/github` on `moa-edge` accepts GitHub's
  signed payload and auto-revokes leaked keys.

## Prerequisites

- P1.4 merged. `require_authz` is in place; handlers enforce.
- A working `make dev` stack with all prior services boot-clean.

```sql
-- API keys for the LocalAuthProvider.
--
-- Wire format: moa_<env>_<32-char-base62-random>_<8-char-lowercase-hex-crc32>
-- Example:      moa_dev_a1B2c3D4e5F6g7H8i9J0k1L2m3N4o5P6_3f9a1b2c
--
-- The `prefix` is the first 18 chars: "moa_<env>_<8-char>". It is indexed
-- and used to narrow the hash lookup. The full key value is never stored;
-- only argon2id(full_key) is.
--
-- `revoked_at` is the canonical "is this key valid" check. A separate
-- table tracks revocation events for audit (OCSF in P1.10).

CREATE TABLE api_keys (
    id              UUID        PRIMARY KEY DEFAULT gen_random_uuid(),
    prefix          TEXT        NOT NULL UNIQUE,
    hash            TEXT        NOT NULL,   -- argon2id PHC string
    -- One of owner_user_id or owner_agent_id is set; the other is null.
    owner_user_id   UUID,
    owner_agent_id  UUID,
    tenant_id       UUID        NOT NULL,
    name            TEXT        NOT NULL,
    -- Free-form note (e.g., "for CI workflow", "Heroku connector").
    description     TEXT,
    -- The environment segment of the key: live | prod | stg | dev.
    -- Mirrored from the key itself so the validator can fail fast on
    -- env mismatch before doing argon2.
    env             TEXT        NOT NULL CHECK (env IN ('live','prod','stg','dev')),
    created_at      TIMESTAMPTZ NOT NULL DEFAULT NOW(),
    last_used_at    TIMESTAMPTZ,
    revoked_at      TIMESTAMPTZ,
    revoked_reason  TEXT,
    -- Once scope FGA tuples are written, set this so the validator can
    -- assert tuple-sync invariant. Optional; the outbox will catch it
    -- shortly after creation.
    scopes_synced_at TIMESTAMPTZ,
    CHECK (
        (owner_user_id IS NOT NULL AND owner_agent_id IS NULL)
        OR
        (owner_user_id IS NULL     AND owner_agent_id IS NOT NULL)
    )
);

CREATE INDEX idx_api_keys_owner_user  ON api_keys(owner_user_id)  WHERE owner_user_id  IS NOT NULL;
CREATE INDEX idx_api_keys_owner_agent ON api_keys(owner_agent_id) WHERE owner_agent_id IS NOT NULL;
CREATE INDEX idx_api_keys_tenant      ON api_keys(tenant_id);
CREATE INDEX idx_api_keys_active      ON api_keys(prefix) WHERE revoked_at IS NULL;

-- Audit log of revocation events. Not the OCSF stream (that's P1.10).
CREATE TABLE api_key_revocations (
    id            UUID        PRIMARY KEY DEFAULT gen_random_uuid(),
    api_key_id    UUID        NOT NULL REFERENCES api_keys(id),
    revoked_at    TIMESTAMPTZ NOT NULL DEFAULT NOW(),
    reason        TEXT        NOT NULL,    -- "user_requested" | "rotation" | "leaked_github" | "deactivation_cascade"
    actor_user_id UUID                       -- who initiated; nullable for system-initiated revocations
);

CREATE INDEX idx_api_key_revocations_key ON api_key_revocations(api_key_id);
```

### 3. Key format module

`crates/moa-auth/providers/src/api_keys.rs`:

```rust
//! API key format, generation, hashing, and validation.
//!
//! Wire format: moa_<env>_<random>_<crc32>
//!
//!   - `moa_`        constant prefix; identifies the secret type for
//!                   secret-scanning partner integrations.
//!   - `<env>`       one of live | prod | stg | dev; chosen by the issuer.
//!   - `_`           separator.
//!   - `<random>`    32 chars from [A-Za-z0-9], 190 bits of entropy.
//!   - `_`           separator.
//!   - `<crc32>`     8-char lowercase hex of CRC32 over everything before
//!                   the trailing `_<crc32>`. Cheap typo check for human
//!                   pasters; not a security feature.

use argon2::{Argon2, PasswordHash, PasswordHasher, PasswordVerifier};
use argon2::password_hash::{rand_core::OsRng, SaltString};
use rand::distributions::Alphanumeric;
use rand::{Rng, RngCore};
use secrecy::{ExposeSecret, SecretString};
use serde::{Deserialize, Serialize};
use sqlx::PgExecutor;
use thiserror::Error;
use uuid::Uuid;

#[derive(Debug, Clone, Copy, PartialEq, Eq, Serialize, Deserialize)]
#[serde(rename_all = "lowercase")]
pub enum Env {
    Live,
    Prod,
    Stg,
    Dev,
}

impl Env {
    pub fn as_str(self) -> &'static str {
        match self {
            Env::Live => "live",
            Env::Prod => "prod",
            Env::Stg  => "stg",
            Env::Dev  => "dev",
        }
    }
    pub fn parse(s: &str) -> Option<Self> {
        match s {
            "live" => Some(Env::Live),
            "prod" => Some(Env::Prod),
            "stg"  => Some(Env::Stg),
            "dev"  => Some(Env::Dev),
            _      => None,
        }
    }
}

/// The full, secret key as returned to the user exactly once at creation.
pub struct IssuedKey {
    pub key: SecretString,        // moa_dev_xxxx_yyyy
    pub prefix: String,            // moa_dev_xxxxxxxx (18 chars)
    pub id: Uuid,
}

#[derive(Debug, Error)]
pub enum ApiKeyError {
    #[error("malformed key: {0}")]
    Malformed(&'static str),
    #[error("CRC mismatch (typo?)")]
    CrcMismatch,
    #[error("unknown environment")]
    UnknownEnv,
    #[error("hash error: {0}")]
    Hash(String),
    #[error("database error: {0}")]
    Database(#[from] sqlx::Error),
    #[error("not found or revoked")]
    NotFoundOrRevoked,
}

/// Generate a new key value. Does not persist.
pub fn generate(env: Env) -> SecretString {
    let random: String = std::iter::repeat_with(|| {
        OsRng.gen_range(0..62)
    })
    .map(|i| match i {
        0..=9   => (b'0' + i as u8) as char,
        10..=35 => (b'a' + (i as u8 - 10)) as char,
        36..=61 => (b'A' + (i as u8 - 36)) as char,
        _ => unreachable!(),
    })
    .take(32)
    .collect();

    let body = format!("moa_{}_{}", env.as_str(), random);
    let crc = crc32fast::hash(body.as_bytes());
    let full = format!("{}_{:08x}", body, crc);
    SecretString::new(full)
}

/// Compute the 18-char prefix for lookup: "moa_<env>_<first-8-of-random>".
pub fn prefix_of(key: &str) -> Result<String, ApiKeyError> {
    let (env, random, _crc) = parse_parts(key)?;
    Ok(format!("moa_{}_{}", env.as_str(), &random[..8]))
}

/// Decompose a key into (env, random, crc-hex), verifying structural
/// invariants and the CRC. Constant-time CRC compare is unnecessary —
/// the CRC is not a secret.
pub fn parse_parts(key: &str) -> Result<(Env, &str, &str), ApiKeyError> {
    let mut parts = key.splitn(4, '_');
    let m = parts.next().ok_or(ApiKeyError::Malformed("no segments"))?;
    if m != "moa" {
        return Err(ApiKeyError::Malformed("missing moa_ prefix"));
    }
    let env_str = parts.next().ok_or(ApiKeyError::Malformed("missing env"))?;
    let random = parts.next().ok_or(ApiKeyError::Malformed("missing random"))?;
    let crc = parts.next().ok_or(ApiKeyError::Malformed("missing crc"))?;

    let env = Env::parse(env_str).ok_or(ApiKeyError::UnknownEnv)?;
    if random.len() != 32 {
        return Err(ApiKeyError::Malformed("random must be 32 chars"));
    }
    if crc.len() != 8 || !crc.chars().all(|c| c.is_ascii_hexdigit()) {
        return Err(ApiKeyError::Malformed("crc must be 8 hex chars"));
    }
    let body = format!("moa_{}_{}", env.as_str(), random);
    let expected = format!("{:08x}", crc32fast::hash(body.as_bytes()));
    if crc.to_ascii_lowercase() != expected {
        return Err(ApiKeyError::CrcMismatch);
    }
    Ok((env, random, crc))
}

fn hash_key(key: &str) -> Result<String, ApiKeyError> {
    let salt = SaltString::generate(&mut OsRng);
    Argon2::default()
        .hash_password(key.as_bytes(), &salt)
        .map(|h| h.to_string())
        .map_err(|e| ApiKeyError::Hash(e.to_string()))
}

fn verify_key(key: &str, phc: &str) -> Result<bool, ApiKeyError> {
    let parsed = PasswordHash::new(phc)
        .map_err(|e| ApiKeyError::Hash(e.to_string()))?;
    match Argon2::default().verify_password(key.as_bytes(), &parsed) {
        Ok(()) => Ok(true),
        Err(argon2::password_hash::Error::Password) => Ok(false),
        Err(e) => Err(ApiKeyError::Hash(e.to_string())),
    }
}

#[derive(Debug, Clone)]
pub struct NewApiKey<'a> {
    pub tenant_id: Uuid,
    pub owner: KeyOwner,
    pub env: Env,
    pub name: &'a str,
    pub description: Option<&'a str>,
}

#[derive(Debug, Clone, Copy)]
pub enum KeyOwner {
    User(Uuid),
    Agent(Uuid),
}

/// Create a new key inside the caller's transaction. The caller is expected
/// to also enqueue the FGA `owner` tuple in the same tx via the outbox.
/// Returns the IssuedKey; the secret is never stored or retrievable again.
pub async fn create<'e, E: PgExecutor<'e>>(
    exec: E,
    new: NewApiKey<'_>,
) -> Result<IssuedKey, ApiKeyError> {
    let key = generate(new.env);
    let prefix = prefix_of(key.expose_secret())?;
    let hash = hash_key(key.expose_secret())?;
    let id = Uuid::new_v4();
    let (owner_user, owner_agent) = match new.owner {
        KeyOwner::User(u) => (Some(u), None),
        KeyOwner::Agent(a) => (None, Some(a)),
    };

    sqlx::query(
        r#"
        INSERT INTO api_keys (id, prefix, hash, owner_user_id, owner_agent_id,
                              tenant_id, name, description, env)
        VALUES ($1, $2, $3, $4, $5, $6, $7, $8, $9)
        "#,
    )
    .bind(id)
    .bind(&prefix)
    .bind(&hash)
    .bind(owner_user)
    .bind(owner_agent)
    .bind(new.tenant_id)
    .bind(new.name)
    .bind(new.description)
    .bind(new.env.as_str())
    .execute(exec)
    .await?;

    Ok(IssuedKey { key, prefix, id })
}

#[derive(Debug, Clone)]
pub struct ResolvedKey {
    pub id: Uuid,
    pub tenant_id: Uuid,
    pub owner_user_id: Option<Uuid>,
    pub owner_agent_id: Option<Uuid>,
}

/// Validate a presented key. Returns the resolved key on success;
/// `NotFoundOrRevoked` if the key is unknown, the hash mismatches, or the
/// key was revoked. Updates `last_used_at` opportunistically (best-effort;
/// errors here are logged not propagated).
pub async fn validate(
    pool: &sqlx::PgPool,
    presented: &str,
) -> Result<ResolvedKey, ApiKeyError> {
    let prefix = prefix_of(presented)?;
    let row: Option<(Uuid, String, Option<Uuid>, Option<Uuid>, Uuid)> = sqlx::query_as(
        r#"
        SELECT id, hash, owner_user_id, owner_agent_id, tenant_id
        FROM api_keys
        WHERE prefix = $1 AND revoked_at IS NULL
        "#,
    )
    .bind(&prefix)
    .fetch_optional(pool)
    .await?;

    let (id, hash, owner_user_id, owner_agent_id, tenant_id) = match row {
        Some(r) => r,
        None => return Err(ApiKeyError::NotFoundOrRevoked),
    };

    if !verify_key(presented, &hash)? {
        return Err(ApiKeyError::NotFoundOrRevoked);
    }

    // Best-effort touch.
    if let Err(e) = sqlx::query("UPDATE api_keys SET last_used_at = NOW() WHERE id = $1")
        .bind(id)
        .execute(pool)
        .await
    {
        tracing::warn!(error = %e, key_id = %id, "failed to touch api_keys.last_used_at");
    }

    Ok(ResolvedKey { id, tenant_id, owner_user_id, owner_agent_id })
}

/// Revoke a key. Idempotent.
pub async fn revoke<'e, E: PgExecutor<'e>>(
    exec: E,
    key_id: Uuid,
    reason: &str,
    actor_user_id: Option<Uuid>,
) -> Result<(), ApiKeyError> {
    sqlx::query(
        "UPDATE api_keys SET revoked_at = NOW(), revoked_reason = $2 WHERE id = $1 AND revoked_at IS NULL"
    )
    .bind(key_id)
    .bind(reason)
    .execute(exec)
    .await?;

    sqlx::query(
        "INSERT INTO api_key_revocations (api_key_id, reason, actor_user_id) VALUES ($1, $2, $3)"
    )
    .bind(key_id)
    .bind(reason)
    .bind(actor_user_id)
    .execute(exec)
    .await?;
    Ok(())
}

        // Flip a character in the random segment.
        let bytes = unsafe { tampered.as_bytes_mut() };

        bytes[mid] = if bytes[mid] == b'a' { b'b' } else { b'a' };
        let err = parse_parts(&tampered).unwrap_err();
        assert!(matches!(err, ApiKeyError::CrcMismatch), "got {err:?}");
    }

    #[test]
    fn hash_and_verify_round_trip() {
        let k = generate(Env::Dev);
        let h = hash_key(k.expose_secret()).expect("hash");
        let ok = verify_key(k.expose_secret(), &h).expect("verify");
        assert!(ok, "verify should accept the original key");
        let mut wrong = k.expose_secret().to_string();
        wrong.pop();
        wrong.push('X');
        let ok2 = verify_key(&wrong, &h).expect("verify");
        assert!(!ok2, "verify should reject a tampered key");
    }
```

### 4. `LocalAuthProvider`

`crates/moa-auth/providers/src/local.rs`:

```rust
//! LocalAuthProvider: only API keys; rejects bearer JWTs.
//!
//! In P1.6 this becomes the canonical impl plugged in via config. P1.5
//! wires it directly into `moa-edge` to replace the placeholder.

use crate::api_keys::{validate, ApiKeyError};
use async_trait::async_trait;
use moa_core::traits::{AuthError, AuthProvider, Credential, Identity, IdentityType};
use sqlx::PgPool;
use std::sync::Arc;

pub struct LocalAuthProvider {
    pool: Arc<PgPool>,
}

impl LocalAuthProvider {
    pub fn new(pool: Arc<PgPool>) -> Self { Self { pool } }
}

#[async_trait]
impl AuthProvider for LocalAuthProvider {
    async fn authenticate(&self, credential: &Credential) -> Result<Identity, AuthError> {
        let key = match credential {
            Credential::ApiKey(k) => k,
            Credential::BearerJwt(_) => {
                // P1.6 adds OIDC + Auth0 here; for P1.5 we reject.
                return Err(AuthError::NotConfigured);
            }
        };

        match validate(&self.pool, key).await {
            Ok(r) => {
                let (identity_type, id) = match (r.owner_user_id, r.owner_agent_id) {
                    (Some(u), None) => (IdentityType::User, u),
                    (None, Some(a)) => (IdentityType::Agent, a),
                    _ => return Err(AuthError::Internal("api_keys owner invariant violated".into())),
                };
                Ok(Identity {
                    identity_type,
                    id,
                    tenant_id: r.tenant_id,
                    api_key_id: Some(r.id),
                    acting_on_behalf_of: None,
                })
            }
            Err(ApiKeyError::Malformed(_) | ApiKeyError::CrcMismatch | ApiKeyError::UnknownEnv) => {
                Err(AuthError::InvalidFormat)
            }
            Err(ApiKeyError::NotFoundOrRevoked) => Err(AuthError::Rejected),
            Err(ApiKeyError::Database(e)) => {
                tracing::error!(error = %e, "api_keys db error during authenticate");
                Err(AuthError::Unavailable("api_keys store unavailable".into()))
            }
            Err(ApiKeyError::Hash(s)) => Err(AuthError::Internal(s)),
        }
    }

    fn name(&self) -> &'static str { "local" }
}
```

```rust
    pub created_at: chrono::DateTime<chrono::Utc>,
    pub last_used_at: Option<chrono::DateTime<chrono::Utc>>,
}

#[restate_sdk::service]
pub trait ApiKeys {
    async fn create(ctx: Context<'_>, req: CreateRequest) -> Result<CreateResponse, HandlerError>;
    async fn list(ctx: Context<'_>) -> Result<Vec<KeyListItem>, HandlerError>;
    async fn rotate(ctx: Context<'_>, id: Uuid) -> Result<CreateResponse, HandlerError>;
    async fn revoke(ctx: Context<'_>, id: Uuid) -> Result<(), HandlerError>;
}

pub struct ApiKeysImpl;

impl ApiKeys for ApiKeysImpl {
    async fn create(ctx: Context<'_>, req: CreateRequest) -> Result<CreateResponse, HandlerError> {
        let identity = require_user_identity(&ctx)?;
        // The caller must be a tenant member to create keys.
        // Use require_authz with the tenant they belong to as scope.
        require_tenant_member(&identity).await?;

        let owner = match req.for_agent_id {
            Some(agent_id) => {
                // To create a key for an agent, the caller must be the agent's operator
                // (or a tenant admin). Check operator first.
                require_agent_operator(&identity, agent_id).await?;
                KeyOwner::Agent(agent_id)
            }
            None => KeyOwner::User(identity.id),
        };

        let pool = pg_pool();
        let mut tx = pool.begin().await
            .map_err(|e| HandlerError::with_status(500, format!("db: {e}")))?;

        let issued = api_keys::create(&mut *tx, NewApiKey {
            tenant_id: identity.tenant_id,
            owner,
            env: req.env,
            name: &req.name,
            description: req.description.as_deref(),
        })
        .await
        .map_err(|e| HandlerError::with_status(500, format!("api_keys: {e}")))?;

        // FGA owner tuple: api_key:<new> owner <user|agent>:<owner>
        let (owner_user_wire, _ut) = match owner {
            KeyOwner::User(u)  => (format!("user:{u}"),  "user"),
            KeyOwner::Agent(a) => (format!("agent:{a}"), "agent"),
        };
        moa_authz::outbox::enqueue_raw(
            &mut *tx,
            moa_authz_schema::TupleOp::Write,
            &owner_user_wire,
            "owner",
            &format!("api_key:{}", issued.id),
            Some(identity.tenant_id),
        )
        .await
        .map_err(|e| HandlerError::with_status(500, format!("outbox: {e}")))?;

        // FGA tenant tuple: api_key:<new> tenant tenant:<T>
        moa_authz::outbox::enqueue_raw(
            &mut *tx,
            moa_authz_schema::TupleOp::Write,
            &format!("tenant:{}", identity.tenant_id),
            "tenant",
            &format!("api_key:{}", issued.id),
            Some(identity.tenant_id),
        )
        .await
        .map_err(|e| HandlerError::with_status(500, format!("outbox: {e}")))?;

        tx.commit().await.map_err(|e| HandlerError::with_status(500, format!("db commit: {e}")))?;

        Ok(CreateResponse {
            id: issued.id,
            key: issued.key.expose_secret().to_string(),
            prefix: issued.prefix,
        })
    }

    async fn list(ctx: Context<'_>) -> Result<Vec<KeyListItem>, HandlerError> {
        let identity = require_user_identity(&ctx)?;
        let pool = pg_pool();
        let rows: Vec<(Uuid, String, String, String, chrono::DateTime<chrono::Utc>, Option<chrono::DateTime<chrono::Utc>>)>
            = sqlx::query_as(
                r#"
                SELECT id, name, prefix, env, created_at, last_used_at
                FROM api_keys
                WHERE owner_user_id = $1 AND revoked_at IS NULL
                ORDER BY created_at DESC
                "#,
            )
            .bind(identity.id)
            .fetch_all(pool)
            .await
            .map_err(|e| HandlerError::with_status(500, format!("db: {e}")))?;
        Ok(rows.into_iter().map(|r| KeyListItem {
            id: r.0, name: r.1, prefix: r.2, env: r.3, created_at: r.4, last_used_at: r.5,
        }).collect())
    }

    async fn rotate(ctx: Context<'_>, id: Uuid) -> Result<CreateResponse, HandlerError> {
        // Rotate = create a new key with the same owner/name/env, revoke the old.
        // For brevity in this prompt: implement as revoke(id, "rotation") + create().
        // The new key's FGA scope tuples are NOT copied automatically — operators
        // who narrowed the old key explicitly must re-narrow the new one. Document
        // this in the CLI output.
        // ... (implementation parallels create + revoke; left as an exercise)
        Err(HandlerError::with_status(501, "rotate: implement before merging P1.5"))
    }

    async fn revoke(ctx: Context<'_>, id: Uuid) -> Result<(), HandlerError> {
        let identity = require_user_identity(&ctx)?;
        // Verify the key belongs to the caller (or the caller is a tenant admin).
        // Single tx: revoke + enqueue outbox delete for the FGA owner tuple.
        let pool = pg_pool();
        let mut tx = pool.begin().await
            .map_err(|e| HandlerError::with_status(500, format!("db: {e}")))?;

        let owner: Option<(Option<Uuid>, Option<Uuid>, Uuid)> = sqlx::query_as(
            "SELECT owner_user_id, owner_agent_id, tenant_id FROM api_keys WHERE id = $1"
        )
        .bind(id)
        .fetch_optional(&mut *tx)
        .await
        .map_err(|e| HandlerError::with_status(500, format!("db: {e}")))?;

        let (owner_user, owner_agent, tenant_id) = owner
            .ok_or_else(|| HandlerError::with_status(404, "not found"))?;

        let is_owner = matches!(owner_user, Some(u) if u == identity.id);
        if !is_owner {
            // TODO: allow tenant admin via require_authz(...tenant.admin...).await
            return Err(HandlerError::with_status(403, "not your key"));
        }

        api_keys::revoke(&mut *tx, id, "user_requested", Some(identity.id))
            .await
            .map_err(|e| HandlerError::with_status(500, format!("revoke: {e}")))?;

        // Tear down the FGA owner edge so a stale key cannot reach resources.
        let owner_wire = match (owner_user, owner_agent) {
            (Some(u), None) => format!("user:{u}"),
            (None, Some(a)) => format!("agent:{a}"),
            _ => return Err(HandlerError::with_status(500, "owner invariant violated")),
        };
        moa_authz::outbox::enqueue_raw(
            &mut *tx,
            moa_authz_schema::TupleOp::Delete,
            &owner_wire,
            "owner",
            &format!("api_key:{id}"),
            Some(tenant_id),
        )
        .await
        .map_err(|e| HandlerError::with_status(500, format!("outbox: {e}")))?;

        tx.commit().await.map_err(|e| HandlerError::with_status(500, format!("db commit: {e}")))?;
        Ok(())
    }
}
```

## Notes

- **The CRC suffix is not security**: it catches paste typos and lets the
  GitHub secret scanner avoid false positives on similar-looking strings.
  The actual security is argon2id over the entire key value.
- **argon2id parameters** use library defaults. The defaults (~32 MiB
  memory, 3 iterations, parallelism 1) are appropriate for an
  authentication path that runs on every request. If validation latency
  becomes a problem in production, tune downward; do not switch hash
  algorithms.
- **Prefix indexing**: the `prefix` column is 18 chars and indexed; the
  full key is hashed. This is the standard "prefix-then-verify" pattern
  used by GitHub, AWS, and most modern API key systems. The first lookup
  is O(log N) on prefix; the second step (argon2 verify) is the expensive
  part but runs at most once per request.
- **Last-used touch is best-effort**: a failure to update `last_used_at`
  is logged and ignored. We do not block authentication on this write.
- **API key as FGA subject** (not the underlying user): scoped keys narrow
  access. Without using `api_key:<id>` as the FGA subject, scoping would
  be silently ignored. Cross-check with P1.4's `fga_subject` helper.
- **Why `moa-auth-providers` and not `moa-api-keys`**: P1.6 adds
  `NullTokenVaultProvider` and `BuiltinAsyncAuthzProvider` alongside.
  Bundling all three provider implementations in one crate avoids
  micro-crating; an `api_keys` module within that crate keeps the
  storage/format details together.
- **`scopes_synced_at` column** is currently unused; it will be populated
  when scope-tuple writes are confirmed in OpenFGA. P1.6 adds the
  scope-management surface (create-with-scope, narrow-scope CLI). For
  P1.5, all keys are unscoped — they have the full permissions of their
  owner.
- **Rotation note**: rotating a key does NOT copy the old key's scope
  tuples. If a key was scoped to "read-only on workspace W", rotation
  produces an unscoped key with the owner's full permissions. The CLI
  output warns about this; P1.6 may add automatic scope copying.
- **CLI identity in P1.5 is read from disk**, not authenticated via API
  key. This is because the CLI is the tool that *creates* the first API
  key — chicken-and-egg. P1.6's "moa auth login" command resolves this
  for daily use. The bootstrap script is a one-off; document it in
  `README.md`.
- **`/v1/whoami` endpoint**: a small handler that returns the inbound
  `Identity` unchanged. Useful for testing the auth pipeline beyond
  P1.5; recommended to keep in tree.
- **GitHub partner registration is a deliberate not-now**: the wiring is
  in place but the endpoint returns 501. Registering with GitHub takes
  weeks of lead time and requires a deployed public endpoint — that
  happens on first public-cloud deploy, not at the engineering level.
