# P1.3 — Identity Context, `moa-edge` Scaffold, and Client `with_identity()`

## Purpose

Make identity propagate from the network edge down through the orchestrator
and out to programmatic clients. Three deliverables land together because
each is meaningless without the other two:

1. A new public-facing HTTP edge crate `moa-edge` that terminates incoming
   credentials, resolves them via a `dyn AuthProvider`, and injects
   `X-Moa-*` identity headers before forwarding the request to the
   orchestrator's Restate handler port.
2. Identity-context extraction in `moa-orchestrator/src/ctx.rs`: a single
   place where every handler reads `Identity` from the request headers.
   Refuses to start in `MOA__AUTH__HEADER_TRUST=strict` mode if headers are
   missing on any inbound call.
3. A `with_identity()` builder on `OrchestratorClient` (in
   `moa-orchestrator-client`) so internal callers — and tests — can attach
   identity to outbound calls without re-implementing the header convention.

End state:

- `moa-edge` binary boots, listens on a configurable port (default 8080),
  exposes `/healthz` and forwards POST `/v1/sessions`, `/v1/sessions/:id/...`
  to the orchestrator's Restate HTTP ingress. It holds a placeholder
  `RejectAllAuthProvider` until P1.5/P1.6 plug in a real one — every real
  request currently returns 401.
- `docker-compose.yml` brings up `moa-edge` on port 8080 (public-facing);
  the orchestrator's port 9080 is removed from the host port mapping (no
  longer exposed outside the compose network).
- `moa-orchestrator-client::OrchestratorClient::with_identity(identity)`
  attaches the `X-Moa-*` headers to every subsequent call.
- `moa-orchestrator/src/ctx.rs` exposes a `RequestIdentity` extractor.

This prompt does not implement any real auth (still no `LocalAuthProvider`)
and does not call `require_authz()` from handlers (P1.4).

## Prerequisites

- P1.2 merged. `moa-core::traits::auth` exports `AuthProvider`,
  `TokenVaultProvider`, `AsyncAuthzProvider`. Orchestrator boots
  cleanly with the outbox poller running.
- A working `make dev` stack.

```rust
//! The header contract between moa-edge and moa-orchestrator.
//!
//! These headers MUST be set by moa-edge on every forwarded request and MUST
//! NOT be settable by external clients (the proxy strips any incoming
//! `X-Moa-*` headers before injecting its own).
//!
//! moa-orchestrator trusts these headers absolutely. Network isolation of
//! the orchestrator's handler port (9080) is the security boundary.

pub const H_IDENTITY_TYPE: &str = "x-moa-identity-type";   // "user" | "agent" | "service"
pub const H_IDENTITY_ID: &str = "x-moa-identity-id";       // UUID
pub const H_TENANT_ID: &str = "x-moa-tenant-id";           // UUID
pub const H_API_KEY_ID: &str = "x-moa-api-key-id";         // UUID, optional
pub const H_ACTING_ON_BEHALF_OF: &str = "x-moa-acting-on-behalf-of"; // UUID, optional

/// All `X-Moa-*` headers, lowercased. Used by the proxy to strip incoming
/// values before injection.
pub const ALL: &[&str] = &[
    H_IDENTITY_TYPE,
    H_IDENTITY_ID,
    H_TENANT_ID,
    H_API_KEY_ID,
    H_ACTING_ON_BEHALF_OF,
];
```

### 4. Proxy core

`crates/moa-edge/src/proxy.rs`:

```rust
//! Forwarding HTTP proxy with identity injection.

use crate::headers;
use moa_core::traits::Identity;
use reqwest::Client;
use std::time::Duration;

pub struct OrchestratorProxy {
    http: Client,
    upstream_base: String,
}

impl OrchestratorProxy {
    pub fn new(upstream_base: impl Into<String>) -> Self {
        Self {
            http: Client::builder()
                .timeout(Duration::from_secs(60))
                .build()
                .expect("reqwest client"),
            upstream_base: upstream_base.into().trim_end_matches('/').to_string(),
        }
    }

    /// Forward a request to the orchestrator, stripping inbound X-Moa-*
    /// headers and injecting fresh ones from the resolved Identity.
    pub async fn forward(
        &self,
        identity: &Identity,
        method: reqwest::Method,
        path: &str,
        body: Vec<u8>,
        request_headers: &axum::http::HeaderMap,
    ) -> Result<reqwest::Response, anyhow::Error> {
        let url = format!("{}{}", self.upstream_base, path);
        let mut req = self.http.request(method, url);

        // Forward all non-X-Moa-* headers verbatim (Content-Type, request id, etc.).
        for (k, v) in request_headers.iter() {
            let kl = k.as_str().to_ascii_lowercase();
            if headers::ALL.iter().any(|h| *h == kl) {
                // Strip; will inject our own below.
                continue;
            }
            // Skip hop-by-hop headers.
            if matches!(kl.as_str(), "host" | "connection" | "keep-alive" | "proxy-authenticate" | "proxy-authorization" | "te" | "trailers" | "transfer-encoding" | "upgrade") {
                continue;
            }
            // Strip incoming Authorization; moa-edge has already consumed it.
            if kl == "authorization" {
                continue;
            }
            req = req.header(k.clone(), v.clone());
        }

        // Inject identity headers.
        req = req
            .header(headers::H_IDENTITY_TYPE, identity_type_str(identity))
            .header(headers::H_IDENTITY_ID, identity.id.to_string())
            .header(headers::H_TENANT_ID, identity.tenant_id.to_string());
        if let Some(k) = identity.api_key_id {
            req = req.header(headers::H_API_KEY_ID, k.to_string());
        }
        if let Some(u) = identity.acting_on_behalf_of {
            req = req.header(headers::H_ACTING_ON_BEHALF_OF, u.to_string());
        }

        if !body.is_empty() {
            req = req.body(body);
        }
        let resp = req.send().await?;
        Ok(resp)
    }
}

fn identity_type_str(identity: &Identity) -> &'static str {
    use moa_core::traits::IdentityType;
    match identity.identity_type {
        IdentityType::User => "user",
        IdentityType::Agent => "agent",
        IdentityType::Service => "service",
    }
}
```

### 5. Routes

`crates/moa-edge/src/routes.rs`:

```rust
//! Edge routes. Phase 1 is intentionally minimal: healthz + a generic
//! proxy. Specific routes get added when the orchestrator's public API
//! surface stabilizes; until then everything under /v1 is forwarded.

use crate::auth::RejectAllAuthProvider;
use crate::proxy::OrchestratorProxy;
use axum::body::Body;
use axum::extract::State;
use axum::http::{HeaderMap, Method, StatusCode, Uri};
use axum::response::IntoResponse;
use axum::routing::{any, get};
use axum::Router;
use moa_core::traits::{AuthProvider, Credential};
use std::sync::Arc;

#[derive(Clone)]
pub struct AppState {
    pub auth: Arc<dyn AuthProvider>,
    pub proxy: Arc<OrchestratorProxy>,
}

pub fn router(state: AppState) -> Router {
    Router::new()
        .route("/healthz", get(|| async { (StatusCode::OK, "ok") }))
        .route("/v1/*rest", any(handle_proxy))
        .with_state(state)
}

async fn handle_proxy(
    State(state): State<AppState>,
    method: Method,
    uri: Uri,
    headers: HeaderMap,
    body: axum::body::Bytes,
) -> axum::response::Response {
    // ---- extract credential ----
    let credential = match extract_credential(&headers) {
        Some(c) => c,
        None => return (StatusCode::UNAUTHORIZED, "missing credential").into_response(),
    };

    // ---- authenticate ----
    let identity = match state.auth.authenticate(&credential).await {
        Ok(i) => i,
        Err(e) => {
            tracing::info!(error = %e, "authentication rejected");
            return (StatusCode::UNAUTHORIZED, "invalid credential").into_response();
        }
    };

    // ---- forward ----
    let path = uri.path_and_query().map(|p| p.as_str()).unwrap_or(uri.path()).to_string();
    let body_vec = body.to_vec();
    let resp = match state.proxy.forward(&identity, method, &path, body_vec, &headers).await {
        Ok(r) => r,
        Err(e) => {
            tracing::error!(error = %e, "proxy forward failed");
            return (StatusCode::BAD_GATEWAY, "upstream unavailable").into_response();
        }
    };

    // ---- pass through status, headers, and body ----
    let status = resp.status();
    let upstream_headers = resp.headers().clone();
    let bytes = match resp.bytes().await {
        Ok(b) => b,
        Err(e) => {
            tracing::error!(error = %e, "read upstream body failed");
            return (StatusCode::BAD_GATEWAY, "upstream read failed").into_response();
        }
    };
    let mut builder = axum::http::Response::builder().status(status);
    for (k, v) in upstream_headers.iter() {
        // Skip hop-by-hop on the way back too.
        let kl = k.as_str().to_ascii_lowercase();
        if matches!(kl.as_str(), "transfer-encoding" | "connection" | "keep-alive") {
            continue;
        }
        builder = builder.header(k.clone(), v.clone());
    }
    builder.body(Body::from(bytes)).unwrap().into_response()
}

fn extract_credential(headers: &HeaderMap) -> Option<Credential> {
    let h = headers.get(axum::http::header::AUTHORIZATION)?.to_str().ok()?;
    if let Some(rest) = h.strip_prefix("Bearer ") {
        // Trim because curl users sometimes append a newline.
        let token = rest.trim().to_string();
        // Heuristic: API key prefixes start with `moa_`. Everything else is a JWT.
        if token.starts_with("moa_") {
            return Some(Credential::ApiKey(token));
        }
        return Some(Credential::BearerJwt(token));
    }
    None
}
```

```rust
mod auth;
mod headers;

mod routes;

use anyhow::Context;
use clap::Parser;
use std::sync::Arc;

#[derive(Parser, Debug)]
struct Args {
    /// Bind address.
    #[arg(long, env = "MOA_EDGE_BIND", default_value = "0.0.0.0:8080")]
    bind: String,

    /// Orchestrator base URL (Restate HTTP ingress).
    #[arg(long, env = "MOA_EDGE_UPSTREAM", default_value = "http://moa-orchestrator:9080")]
    upstream: String,
}

#[tokio::main]
async fn main() -> anyhow::Result<()> {
    tracing_subscriber::fmt()
        .with_env_filter(
            tracing_subscriber::EnvFilter::try_from_default_env()
                .unwrap_or_else(|_| tracing_subscriber::EnvFilter::new("info,moa_edge=debug")),
        )
        .json()
        .init();

    let args = Args::parse();
    tracing::info!(bind = %args.bind, upstream = %args.upstream, "starting moa-edge");

    let state = routes::AppState {
        auth: Arc::new(auth::RejectAllAuthProvider),
        proxy: Arc::new(proxy::OrchestratorProxy::new(&args.upstream)),
    };

    let app = routes::router(state);
    let listener = tokio::net::TcpListener::bind(&args.bind)
        .await
        .with_context(|| format!("bind {}", args.bind))?;

    axum::serve(listener, app)
        .with_graceful_shutdown(shutdown_signal())
        .await?;
    Ok(())
}

async fn shutdown_signal() {
    let _ = tokio::signal::ctrl_c().await;
    tracing::info!("moa-edge: shutdown signal received");
}
```

### 7. Identity extraction in the orchestrator

Edit `crates/moa-orchestrator/src/ctx.rs`. Add the following without disturbing
existing code; place it at the end of the file:

```rust
// ---------------- identity extraction (P1.3) ----------------
//
// moa-edge injects X-Moa-* headers on every forwarded request. We trust
// them absolutely. Network isolation of the handler port (9080) is the
// security boundary; see docs/architecture/decisions/0002-auth-architecture.md.

use moa_core::traits::{Identity, IdentityType};
use uuid::Uuid;

#[derive(Debug, thiserror::Error)]
pub enum IdentityHeaderError {
    #[error("missing identity header: {0}")]
    Missing(&'static str),
    #[error("malformed identity header: {0}")]
    Malformed(&'static str),
    #[error("unknown identity type: {0}")]
    UnknownType(String),
}

/// Mode for identity extraction. `Strict` rejects missing headers; `Lenient`
/// returns Ok(None) so dev-time stacks with the placeholder provider don't
/// blow up. Configured via MOA__AUTH__HEADER_TRUST=strict|lenient.
#[derive(Debug, Clone, Copy, PartialEq, Eq, Default)]
pub enum HeaderTrustMode {
    Strict,
    #[default]
    Lenient,
}

pub fn extract_identity(
    headers: &restate_sdk::http::HeaderMap,
    mode: HeaderTrustMode,
) -> Result<Option<Identity>, IdentityHeaderError> {
    let get = |name: &'static str| headers.get(name).and_then(|v| v.to_str().ok());

    let raw_type = get("x-moa-identity-type");
    let raw_id = get("x-moa-identity-id");
    let raw_tenant = get("x-moa-tenant-id");

    // All-or-nothing: either we have all three required headers or none.
    match (raw_type, raw_id, raw_tenant) {
        (None, None, None) => {
            if mode == HeaderTrustMode::Strict {
                return Err(IdentityHeaderError::Missing("x-moa-identity-type"));
            }
            return Ok(None);
        }
        (Some(_), Some(_), Some(_)) => {}
        _ => {
            return Err(IdentityHeaderError::Malformed(
                "partial identity headers; require all of type/id/tenant",
            ));
        }
    }

    let identity_type = match raw_type.unwrap() {
        "user" => IdentityType::User,
        "agent" => IdentityType::Agent,
        "service" => IdentityType::Service,
        other => return Err(IdentityHeaderError::UnknownType(other.to_string())),
    };
    let id = Uuid::parse_str(raw_id.unwrap())
        .map_err(|_| IdentityHeaderError::Malformed("x-moa-identity-id"))?;
    let tenant_id = Uuid::parse_str(raw_tenant.unwrap())
        .map_err(|_| IdentityHeaderError::Malformed("x-moa-tenant-id"))?;
    let api_key_id = get("x-moa-api-key-id")
        .map(|v| Uuid::parse_str(v).map_err(|_| IdentityHeaderError::Malformed("x-moa-api-key-id")))
        .transpose()?;
    let acting_on_behalf_of = get("x-moa-acting-on-behalf-of")
        .map(|v| Uuid::parse_str(v).map_err(|_| IdentityHeaderError::Malformed("x-moa-acting-on-behalf-of")))
        .transpose()?;

    Ok(Some(Identity {
        identity_type, id, tenant_id, api_key_id, acting_on_behalf_of,
    }))
}
```

### 8. Wire the extractor at handler entry

For Phase 1, identity extraction is *invoked* but not yet *enforced* on any
specific handler — that's P1.4. The job here is to make it ergonomic.

Add a `ctx::with_identity()` helper that handlers will call:

```rust
/// Extract the identity from the current Restate handler's headers,
/// using the orchestrator's configured trust mode. Logs at debug level.
pub fn current_identity(
    ctx: &restate_sdk::Context<'_>,
) -> Result<Option<Identity>, IdentityHeaderError> {
    let mode = HEADER_TRUST_MODE.get().copied().unwrap_or(HeaderTrustMode::Lenient);
    let headers = ctx.metadata().headers(); // adapt to Restate SDK shape
    extract_identity(headers, mode)
}

pub static HEADER_TRUST_MODE: std::sync::OnceLock<HeaderTrustMode> = std::sync::OnceLock::new();
```

Initialize `HEADER_TRUST_MODE` from config in `main.rs`:

```rust

        _ => None,
    })
    .unwrap_or(HeaderTrustMode::Lenient);
let _ = ctx::HEADER_TRUST_MODE.set(mode);
```

### 11. Docs

Add `docs/operations/edge-network-isolation.md`:

```markdown
# Edge network isolation

`moa-edge` is the only MOA service that should be exposed to untrusted
networks. The orchestrator (`moa-orchestrator`, port 9080) trusts the
`X-Moa-*` identity headers absolutely — anyone who can reach port 9080
can impersonate any user or agent.

## Compose

Port 9080 is bound to the compose internal network only, never to host
0.0.0.0. The `docker-compose.yml` removes the public mapping; if a developer
needs local-host access for debugging, bind to `127.0.0.1:9080:9080` and
document it as a developer-only override.

## Production / k8s

- The orchestrator Service is `ClusterIP` (or `Internal`), never
  `LoadBalancer` or `NodePort`.
- A NetworkPolicy permits ingress to port 9080 only from the `moa-edge`
  pod selector.
- If a service mesh is in use (Linkerd, Istio), require mTLS between
  `moa-edge` and the orchestrator.
- Verify exposure on deploy: `kubectl get svc moa-orchestrator -o
  jsonpath='{.spec.type}'` returns `ClusterIP`.

## Failure mode

A misconfigured deployment that exposes 9080 publicly bypasses authn and
authz entirely. There is no in-band defense; the design relies on the
network boundary. P1.10 adds a deploy-time runbook check.
```

Update `docs/01-architecture-overview.md` Auth Layer section (added by P1.0)
to point to this new operations doc.

## Notes

- **Why a placeholder provider, not a feature-flag?** The crate must
  compile and the binary must boot so the rest of the stack can be
  exercised end-to-end before P1.5/P1.6 land. A feature flag would create
  a "doesn't compile without auth0" failure mode that bites contributors
  who haven't run the auth pack yet. The placeholder is a known-401 and is
  replaced in P1.6.
- **All-or-nothing header set**: tightening this — requiring either all
  three core headers or none — catches misconfigurations early. A handler
  with partial identity is almost always a bug in the proxy.
- **`Lenient` vs `Strict` mode**: dev stacks use Lenient so handlers that
  don't yet call `require_authz` can boot without identity. Production
  flips to `Strict`. P1.10's deploy runbook will enforce this.
- **Authorization header stripping**: the edge consumes the credential
  and strips it from the forwarded request. The orchestrator never sees
  the raw token. This matters for log hygiene and for ensuring a downstream
  service can't accidentally re-use the credential out-of-band.
- **`X-Moa-*` headers are stripped from inbound requests** before
  injection. External clients cannot forge identity by setting these
  headers themselves — the edge unconditionally overwrites them.
- **`uri.path_and_query()` forwarding**: query strings ride along. Don't
  reconstruct the URL by hand; use the inbound `Uri`'s path+query as-is.
- **mTLS between edge and orchestrator** is *not* in scope for P1.3.
  Network isolation alone is the boundary; mTLS is a Phase 4 hardening
  step (see ADR-0002 revisit condition 3).
- **The proxy is a forward proxy, not a reverse proxy for Restate
  introspection**. Operators who need to talk to the Restate admin API
  (`/restate/v1/...`) must port-forward into the cluster or expose the
  admin port separately. The edge does not forward `/restate/...`.
- **Why not `tower::Service` directly**: axum gives us the same surface
  with friendlier ergonomics for header munging. The proxy logic is small
  enough that the abstraction isn't earning its keep.

## What P1.4 expects

- `ctx::current_identity(ctx)` returns the inbound `Identity` (or `None`
  in Lenient mode).
- The orchestrator client's `with_identity()` is available for tests that
  need to invoke handlers under specific principals.
- `moa-edge` is in the compose stack; tests against the public surface use
  `http://localhost:8080`, tests against handlers directly bypass the edge
  and talk to `http://moa-orchestrator:9080` from inside the compose
  network (or, on host, by temporarily re-binding 9080 to 127.0.0.1).
